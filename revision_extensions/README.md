# 论文补充实验 3—6：手动运行说明

本代码承接已经提供的实验 1、2，构成 **模型来源与数值筛查 → 安全与任务定义 → 基线比较 → 组件解释 → 敏感性与泛化 → 规模和计算成本** 的证据链。交付时只进行了源码静态审查、配置文件结构检查与文件完整性检查；**没有执行 Python、CMD、导入测试、训练、推理或实验**。因此不能宣称已经通过运行验证，也不能预先保证算法胜出或审稿意见全部解决。

## 文件位置与运行顺序

四个入口均放在原论文目录，双击对应 CMD 即可。CMD 必须与 `revision_extensions`、原有 `revision_experiments` 文件夹放在一起；不要单独移走 CMD。

```text
C:\Users\zhengzihao\Desktop\RL-for-charging-main\
  run_experiment_1.cmd                 原有入口
  run_experiment_2.cmd                 原有入口
  run_experiment_3.cmd                 公平基线比较
  run_experiment_4.cmd                 组件消融
  run_experiment_5.cmd                 奖励/探索敏感性与冻结策略泛化
  run_experiment_6.cmd                 规模、计算成本与审稿证据汇总
  revision_experiments\                原有实验 1、2 和 SPMe 模型，保持原文件
  revision_extensions\                本次新增源码和四份配置
  revision_results\experiment_3\时间戳\
  revision_results\experiment_4\时间戳\
  revision_results\experiment_5\时间戳\
  revision_results\experiment_6\时间戳\
  revision_cache\                      缓存，不在桌面其他位置散落输出
```

**顺序为 1 → 2 → 3 → 4 → 5 → 6。** 代码现在可以准备好，但正式运行依赖此前的实际结果。E1 必须生成通过数值精度与模型筛查的 `handoff.json`；E2 至少观察到一个满足任务及安全口径的成功回合。这个门槛只是允许后续探索，不代表 E2 已全面证明安全。E4、E5、E6 还会核对前序运行目录、模型和源码哈希。缺少结果、最新运行失败、模型文件被修改或来源不一致时，明确停止，不使用虚构结果或悄悄退回旧参数。

依赖环境沿用原目录的 `.venv-revision` / `.venv-reproduce` 和锁定版本。只有手动启动 CMD 后，才会检查或安装依赖。需要 Python 3.11/3.12；首次安装可能联网。可通过 `REPRO_PYTHON` 指定解释器，`REPRO_PIP_INDEX_URL` 指定镜像。相同版本不保证不同硬件和线程下逐位一致，运行时保留环境记录。

支持自定义配置，例如在原目录终端运行 `run_experiment_3.cmd --config "C:\完整路径\experiment_3.json"`。配置先保存，再训练。上游目录默认读取 `LATEST_COMPLETED.txt`，同时检查 `LATEST_STARTED.txt`；若明确采用旧的完整运行，在 JSON 中增加 `"upstream_results": {"1": "C:\\...\\experiment_1\\时间戳", "2": "C:\\...\\experiment_2\\时间戳"}`，并对所有后续实验保持同一条来源链。路径必须位于原目录相应实验的结果文件夹内。

## 实验 3：基线是否公平、优势是否存在

- 离散组：QMIX、离散 MAPPO、集中式 DQN、共享参数 IQL、采样 CC-CV、SOC 反馈规则。每节电芯动作 0—7.5 A，间隔 0.5 A；DQN 的三电芯联合动作数为 4096。
- 连续组：连续 MAPPO、连续 SAC、连续采样 CC-CV。保留连续电流，不将 SAC 输出伪装为离散动作。主要算法归因在各自动作组内完成。
- 每个学习算法用 3 个预先固定学习率 × 3 个独立调参种子 × 12,000 次整包交互，按验证成功率、约束满足率及失败惩罚时间依次选参。正式训练使用另外 5 个种子，每种子 60,000 次整包交互；每 10,000 步阈值检查验证性能。测试集不参与选参、选种子、选检查点。
- 8 个随机验证初态；48 个不同的随机测试初态。另列训练中出现过的 A/B 两个诊断初态，不混入未见初态结果。
- 各算法交互预算相同，优化器更新规则不同并明示：序列价值方法每 50 步一批序列更新；SAC 每 50 步进行 50 次更新、批量 256；MAPPO 累积至少 2048 步后按 10 个 epoch 更新。不能称为完全相同算力预算。
- CC-CV 是采样反馈控制，CC 电流从 2/4/7.5 A 中按验证集选择。规则控制都有观测 SOC 向 0.93 靠近的终端限流，避免一节过冲后其他电芯永久停在 0.90。终端目标、上限和处理细节在 `protocol.json`、`decisions.csv` 中记录；不声称理想模拟电路 CC-CV。
- DQN/SAC 使用集中式信息，QMIX 的局部网络与 MAPPO 的局部 actor 使用局部输入及电芯身份；这些信息结构差异明确披露。共同安全层可使用全包观测。

## 实验 4：组件为什么必要

完整继承 E3 QMIX 的训练配置、学习率、验证集和测试集，**每个版本重新初始化并训练**：完整 QMIX、去 GRU、VDN 加法混合器、去状态条件超网络的静态单调混合器、去混合器但共享参数的 IQL、保留混合器但取消局部参数共享、独立 IQL，以及仅取消均衡奖励项。

单项消融用于对应机制解释；独立 IQL 同时改变混合和共享，是多因素参照。报告实际参数量，不把隐藏宽度一致等同于参数量一致。安全层与任务成功定义始终保持一致；无保护与同权重加保护的因果对照已经归属于 E2。不得删除原模型组件直接推理冒充重新训练的消融结果。

## 实验 5：奖励依赖、探索依赖和冻结泛化

奖励/探索组包括原始参考权重、全 1 原始权重、固定物理尺度归一化后的全 1 权重、均衡/电压/温度权重分别减半与加倍、epsilon 起点 0.5 对 1.0；所有版本重新训练。失败惩罚单列。固定学习率沿用 E3 验证选择；所有敏感性版本使用同一套新的验证和测试初态。另训练域随机化 QMIX，不用最终测试数据选择扰动范围。

泛化组冻结 E3 全部 QMIX/MAPPO 种子，以及本实验参考/域随机化 QMIX 的全部种子，共 20 个模型。100 个随机初态 + 100 个初始均衡初态，配对测试标称环境、15/34/35°C、参数 ±5%/±10%、两级传感噪声、传感偏置、一个决策周期的延迟、900 秒时电流上限下降 30%，共 13 类条件。**35°C 初始温度高于固定筛选裕量允许的 308 K，明确作为不可行负对照；不能把该组必然拒绝解释成某算法泛化差。** 上限下降是每节电芯的电流权限变化，不是共享供电或恒功率模型。离散 5.25 A 上限向下量化为 5.0 A。

默认泛化测试为 **13 × 200 × 20 = 52,000 个回合**，另外还有 55 次正式训练、2640 个敏感性测试回合，计算和存储负担很大。完整原始轨迹以 `trajectory.csv.gz` 无损压缩保存，解压后为 CSV；不删失败样本。可以在运行前声明较小的探索配置，但不得将少量种子/少量案例结果表述为默认完整实验，更不能观察结果后删掉困难工况。

记录策略实际使用的延迟/噪声观测、请求电流、安全层执行电流、筛选原因、奖励项及其激活次数。安全层可能使电压/温度软惩罚很少激活：这类结果只能说明受保护系统对权重的敏感性，不能证明原始无保护奖励普遍稳健。

## 实验 6：规模与计算开销

QMIX/MAPPO 分别在 3/6/12 节规模重新训练，每个规模各 5 个种子；学习率沿用 E3 对应方法。三节辨识电芯的参数和训练/测试 SOC 三元组重复扩展，保持初态分布可比。这是合成规模试验，不是新增电芯实测数据，也不是跨电芯数量的零样本迁移。电压/温度惩罚继续按电芯求和，随规模变化的奖励幅度是明确的解释限制。

记录完整训练时间、测试时间、策略/安全筛选/物理求解/初始化分项、参数量与已训练策略 CPU 推理分位数。另对 24/48/96/192 节**未训练网络**独立做合成输入的纯策略计时；该组没有闭环控制成功率，不能当成大电池包控制验证。没有共享供电、串联电路或电芯间热耦合，PC 耗时不能等同于微控制器部署结果。

## 所有实验的统一判定口径

每次决策 90 秒，充电时限 5400 秒；充电终止需所有 SOC ≥ 0.90 且全包 SOC 标准差 ≤ 0.02，然后零电流保持 270 秒。物理上限与目标下限分开：SOC 上限 0.95、电压 4.2 V、温度 309 K。安全预测裕量继承 E2；实物元数据若在 E1 未确认，在后续仍为未确认。

安全控制是有限候选、有限预测时域的数值筛选，另有模拟被控对象的事件保护。包含电流切换端点、最多 1 秒采样的稠密约束审计；**没有连续时间不变集、所有扰动或实物安全保证**。数值失败、保护停机、筛选不可行、保持失败、超时均保留。将已观察到的物理上限是否满足，与安全审计是否完整、任务是否成功分开报告。

策略选择看验证集；最终测试比较使用相同工况/同训练种子的配对差异。规则控制不复制成虚假的独立训练样本。报告按种子 bootstrap 的条件置信区间、符号翻转检验与预先约定检验族内 Holm 校正。仅 5 个非零种子差异时双侧精确检验的最小 p 值为 0.0625，不会强行得到显著结果。低检验功效不等于方法等效。

失败时的惩罚充电时间固定为 5400+270 秒，并与成功率同时报告；共同成功子集才比较充电时间、SOC 标准差积分和输入 Wh。输入 Wh/Ah 不是损耗、效率或寿命，须连同终端 SOC 解释。先看失败和任务完整性，不能只凭奖励曲线或一张好看的轨迹宣布复现成功。

## 结果文件与闭环

| 文件 | 含义 |
|---|---|
| `status.json` / `run.log` | 是否计算结束、异常信息；completed 不等于论文主张成立 |
| `requested_config.json` / `effective_config.json` / `protocol.json` | 用户配置、实际配置与预先固定的实验协议 |
| `lineage.json` / `e1_model_used.json` / `source_snapshot` / `provenance.json` | 上游结果来源、辨识参数、代码快照、软件版本和哈希 |
| `model_registry.json` / `training.csv` / `validation.csv` / `selected.pt` / `learning.png` | 模型身份、完整训练历史、验证选择和学习曲线 |
| `episode_metrics.csv` / `summary.csv` / `REPORT.md` | 包含失败的逐回合结果与按方法、规模、工况、初态类型分组的统计 |
| `paired_comparison_summary.csv` 等 | 配对效应及不确定性；E5 奖励比较位于 `sensitivity_statistics`，泛化另列配对退化 |
| 每个测试回合中的 `trajectory.csv.gz` / `decisions.csv` / `metrics.json` / `case.json` | 原始数据、决策审计和工况；各模型前两个预先排列案例另输出轨迹图 |

每次启动创建新时间戳文件夹，保留失败和中断的部分结果。权重文件可用于后续冻结评估，但本轮未实现包含物理求解器、回放缓存和批次状态的完整断点续跑；重新启动会生成新一轮实验。运行中不要同时修改源码，也不要同时启动相同编号造成最新指针混淆。

## 拒稿意见能回答到什么程度

E3 对应 MAPPO/PPO/SAC、DQN/IQL 和比较合理性；E4 对应 GRU、混合器、超网络及均衡机制；E5 对应动态扰动、泛化、奖励单位权重与 epsilon；E6 对应规模、计算成本和证据汇总。E1 的数据来源限制和 E2 的安全结果贯穿所有后续实验。

硬件闭环、微控制器实测、真实新电芯/新温度验证、退化寿命模型、IL 实验和一般收敛证明仍未由本代码完成。文稿还需按实际结果修改方程、方法动机、局限性和相关文献；不能仅凭程序输出宣称所有拒稿意见已解决。
