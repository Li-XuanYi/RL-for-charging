# 现有材料的数值实验重建

这是基于原文件夹补建的可运行实验入口，不是已证明与论文数值一致的完整复现。原论文、原代码、实测数据均保留。新增代码在 reproduction，所有实验输出在项目根目录 reproduction_results。没有连接或控制真实电池设备。

## 一键运行（Windows CMD）

在 CMD 中执行：

```bat
"C:\Users\zhengzihao\Desktop\RL-for-charging-main\run_reproduce.cmd" quick
```

完整训练预算：

```bat
"C:\Users\zhengzihao\Desktop\RL-for-charging-main\run_reproduce.cmd" full
```

不带参数或双击 CMD 默认 quick，结束后保留窗口。首次运行自动寻找 Python 3.11/3.12，优先利用本机已有解释器，建立项目内 .venv-reproduce 环境，安装固定版本依赖。不会把依赖装进原 conda 环境。依赖默认从清华 PyPI 镜像下载；可设置 REPRO_PIP_INDEX_URL=https://pypi.org/simple 改用官方源。Python 路径也可用 REPRO_PYTHON 指定。

| 模式 | 每节电芯 PSO | 每组 SOC 的训练回合 | 用途 |
|---|---|---|---|
| smoke | 2 粒子，1 次迭代 | 2，单回合最多 4 步 | 接口和输出测试，不能判断算法性能 |
| quick | 6 粒子，5 次迭代 | 30，单回合最多 50 步 | 小规模试跑，不能视为收敛结果 |
| full | 30 粒子，100 次迭代 | 1200，单回合最多 50 步 | 较完整的计算预算，仍需看实际指标与收敛性 |

每次都会分别训练 Set A=[0.1,0.2,0.3]、Set B=[0.3,0.5,0.7]；固定随机种子 7。可追加 `--seed 8` 验证另一个随机种子，`--episodes 100` 调整每组训练回合。默认 CPU，避免原代码 cuda:3 的设备问题。完整实验可能较久，不预设运行时间或保证达到论文指标。

## 数据流与保存内容

1. 读取原 data_true/data_image 中三组一维电压和温度数组，按原脚本的 1 秒间隔恢复时间轴，保存标准 CSV 和文件 SHA256。
2. 重绘三节电芯的实测放电曲线，对应论文图 4。
3. 从实测数据重新做 PSO 参数辨识，输出拟合电压、温度曲线、每次迭代的最佳误差和辨识参数。用整段实测时间计算误差；如果模型提前终止，记录覆盖率并惩罚，而不是通过裁短实测数据降低误差。
4. 将三组新拟合参数传入 SPMe 仿真环境，使用原 NN.py 中 DRQN、QMIXNET 网络架构训练两组场景。每 25 回合及结束时保存模型，每回合保存奖励和损失。
5. 重新加载保存的模型，无探索评估；运行一个基于原 CC-CV equalization.py 重建的 CC 后均衡基线。
6. 保存 SOC、电流、电压、温度、均衡时间、是否全部达到 90%、充入/放出电量与端口输入能量，以及 PNG 图表。

每次输出到 `reproduction_results/日期时间_模式/`，不覆盖上一次实验。

| 路径 | 内容 |
|---|---|
| reproduction_results/LATEST.txt | 最近一次运行目录 |
| config.json / data_provenance.json | 参数、软件版本、假设和原始数据哈希 |
| raw/ | 三节电芯的实测数据 CSV |
| fit/ / fitted_parameters.json | 拟合结果、RMSE、PSO 历史、模型覆盖率、重新辨识的参数 |
| training/ | 两组训练奖励、损失、终止标志 |
| checkpoints/ | 两组 PyTorch 模型及优化器状态 |
| trajectories/ | 评估与基线的逐时刻数据；同时记录请求电流和过滤后电流 |
| figures/ | 实测、拟合、训练、控制曲线 PNG |
| summary.csv | 均衡时间、达到 90% 的时间、最终 SOC、温度电压最大值等 |
| status.json / run.log | 完成或失败状态、错误及运行日志 |

`status=completed` 只表示计算流程结束；是否成功充电必须检查 `target_reached` 和 `balanced_target90_time_s`。空白时间表示在当前时限内没有达到目标，不能当作 0 秒。程序不会填入论文声称的 1890/2520 秒，也不会补造缺失的 DQL 曲线。

若已完成参数辨识，可复用结果再训练，减少耗时：

```bat
run_reproduce.cmd full --fit-from "C:\Users\zhengzihao\Desktop\RL-for-charging-main\reproduction_results\实际运行目录\fitted_parameters.json"
```

模型文件包含优化器状态，但当前入口不提供精确训练断点续跑（还需要回放缓冲区和随机数状态）。中断后保留数据与最近模型，重新运行会创建新目录。

## 与论文、原实现的区别及缺口

- **原代码直接运行会失败**：SPM.step 没有返回值，但 MultiSPM.multi_step 对其解包；经验回放的最后 next observation 重复了旧状态；目标网络每次学习都同步；只依赖 done 计算训练序列长度时可能产生空序列。本入口重写环境衔接与训练逻辑，保留原网络类副本 vendor/NN.py。
- **不是完整原始工程**：找不到 DQL 实现、训练好的模型、三节电芯完整辨识参数、原充电轨迹与硬件通信接口。因此缺失 DQL 不用其他算法冒充，实物验证不执行。
- **电流矛盾**：论文为 4 Ah 电芯、1C 放电，原辨识脚本传入 5 A。默认采用论文口径 4 A，可追加 `--ident-current 5` 按代码口径重建；复用拟合参数时电流必须相符。仅凭现有数据文件无法核实实际采集电流和采样元信息。
- **模型不同**：沿用代码的 SPMe+Chen2020 参数基础，论文正文写的是 SPM 和三星 40T。不会把该参数集称作已验证的三星电芯精确模型。SOC 使用模型负极平均锂浓度与该参数集 0/100% 化学计量端点计算；替换了原脚本硬编码 SOC 常数。
- **辨识是重建**：原 PSO 仅对六个电化学参数拟合电压，未提供完整热参数辨识。本入口在原六参数范围上加入换热系数、比热缩放系数，联合拟合电压与温度。目标为 V_RMSE/0.05 + T_RMSE/1 + 覆盖缺失惩罚。这不是原论文报告 RMSE 的精确再现；也是同一数据上的拟合误差，不是独立验证误差。
- **MBA-RL 设置**：保持 MLP-GRU-MLP、单调混合网络、128/256 隐层、RMSprop、2e-4 学习率、0.99 折扣、奖励系数 -0.75/-50/-20/-2；采用论文非负动作 0~7.5 A、0.5 A 间隔和 90 秒步长，目标 SOC>=0.9 且标准差<=0.02，目标网络每 50 回合同步。探索率沿用原 main.py 从 0.5 衰减，而不是声称已经解决审稿人对此的质疑。
- **增加了仿真安全过滤**：先试算请求电流的 90 秒响应，遇到电压/温度事件则减小电流并从同一状态重算。0 A 也不可行时直接报错，不伪造后续数据。额外过滤会改变原算法行为；它使用仿真状态，不能直接称为可部署的实物安全控制。输出记录过滤次数。
- **CC 基线只能重建原有启发式**：原脚本达到电压阈值后停止外部充电，执行成对能量再分配，且中间电芯单周期被推进两次。本入口统一各电芯 90 秒步长，保留 CC 后成对均衡思路，阈值依论文设为 4.0 V。没有真实 CV 闭环或变换器效率模型，因此名称明确为 CC_then_balancing_reconstructed，不能据此声称严格优于标准 CC-CV。
- **比较终点不同**：均衡基线在 SOC 标准差达标时停止；MBA-RL 继续至全部达到 90%。因此只报告各自实际达到的条件，不把两者终端 SOC 直接当作等任务充电性能比较。能量指标仅为各电芯端口的数值积分，不是变换器损耗、往返效率或健康度。
- **评价范围**：目前为两个固定初始 SOC、单随机种子、固定 25 摄氏度环境；不构成动态适应性、大规模扩展性或实物鲁棒性证明。

## 本机实际试跑记录（2026-09-19）

- 已通过基础数值检查和 pip check。
- CMD 的 smoke 模式完成，用时约 31 秒（不含首次依赖安装）；每组仅 2 回合，不达标属于预期范围。
- CMD 的 quick 模式完成，用时约 307 秒（约 5 分钟，不含首次依赖安装）；每组 30 回合，输出目录为 reproduction_results/20260919_212829_005420_quick。
- quick 的无探索评估中，Set A 首次均衡 1710 秒，均衡且全部达到 90% 为 3150 秒；Set B 对应为 1350 秒和 3420 秒。Set B 首次均衡后发生过再次失衡，因此本次结果不支持“始终维持均衡”的论文主张。
- quick 的电压拟合 RMSE 约为 0.162、0.153、0.174 V；温度约为 0.497、0.680、0.614 摄氏度。均未对齐论文报告的误差，4 A/5 A 电流口径及模型参数问题仍需核实。
- 这些数值仅描述当前重建版本的一次试跑。full 的 1200 回合训练预算尚未实际跑完，也没有复现缺失的 DQL 或实物控制实验。
- requirements-lock.txt 记录本机已验证的全部依赖版本，CMD 实际按此锁定文件安装；requirements.txt 为主要依赖摘要。
